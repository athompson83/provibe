# Product Strategy

## Category
**Control Center for AI-Built Software**

Secondary descriptor: **An independent technical chief of staff for vibe-coded software projects.**

Do not lead with “AI code explainer” or “AI cofounder.” Code explanation and generic prompt generation are increasingly commoditized. The durable position is an independent layer above the tools customers already use.

## Positioning
> **Bring your own agent, codebase, accounts, and infrastructure.**

Core promise:
> **Know what to build, what your agent actually finished, what is live, what could break, and exactly what to do next.**

## Modules
1. **Blueprint Studio** — start/import/rescue/launch-prep, adaptive interview, scope challenge, artifact generation, screen specs, tool-specific build package.
2. **Build Control Center** — portfolio, cockpit, decisions, reports, evidence, prompts, ETA, readiness, provider status.
3. **Application Intelligence** — code explorer, application map, database explorer, deployments, change translator, risks, Ask My App.
4. **Progress Verification** — report ingestion, atomic claims, evidence matching, contradiction/blocker detection, verdict, next/handoff/recovery prompt.

## Primary customer
Nontechnical or semi-technical founder with an already-started AI-built app who no longer trusts or understands the project state. “Rescue my app” should be the highest-urgency acquisition wedge.

## Secondary customer
Freelancers and AI development studios managing multiple client projects. Higher willingness to pay for standardized onboarding, evidence-backed reporting, handoff, and portfolio oversight.

## Jobs to be done
Define, orient, verify, reconcile, decide, recover, hand off, and launch.

## Defensibility
Canonical project graph, evidence-backed status, cross-agent adapters, living project memory, code/runtime/database reconciliation, outcome-calibrated estimates, compatibility registry, and launch-readiness framework.

## Business model hypothesis
- Free Health Check: $0.
- Blueprint Pack: $59 one-time.
- Builder: $39/mo, one monitored project.
- Founder: $79/mo, up to five projects.
- Studio: $199/mo+.
- Enterprise: custom.

Meter expensive analysis/image operations, not Markdown file count.

## Kill/pivot signals
Weak return usage after initial generation; reluctance to connect read-only providers; claim verification adds no value beyond generic summaries; unsupported-stack support dominates; or per-project cost destroys target gross margin.
