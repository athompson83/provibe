# Market Positioning Notes

## Crowded areas to avoid leading with
Generic repo chat, architecture diagrams, code explanation, AI PRD/master-prompt generation and “AI cofounder builds everything” platforms.

## Differentiated position
**Bring your own agent, codebase, accounts and infrastructure.** ProVibe sits above Codex/Claude/Cursor/GitHub/Vercel/Supabase as an independent project-memory, application-intelligence and verification layer.

## Strategic wedge
The strongest early customer may already be stuck: partially built app, conflicting agent reports, unclear production state, docs drift and no reliable beta verdict. Rescue has urgency and demonstrates verification value immediately.

## Recurring-value thesis
Blueprint creation acquires. Application understanding builds trust. Progress verification creates recurring use. Persistent memory/readiness creates switching cost.

## Competitive response
If coding agents improve planning/explanation, ProVibe should benefit because its moat is independent evidence, cross-tool memory and outcome state—not proprietary prompt wording.
