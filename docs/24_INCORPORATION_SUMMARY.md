# Incorporated Product Expansion

The original application-intelligence idea is deliberately merged with the broader vibe-coding project-control concept rather than treated as separate products.

## Unified modules
- Blueprint Studio.
- Build Control Center.
- Application Intelligence.
- Progress Verification.

## Key additions incorporated
Four entry modes; adaptive founder interview/challenge; canonical model; project-specific artifact bundles; design reference + machine-readable screen workflow; multi-prompt system; cross-agent adapters; portfolio/cockpit; claimed-vs-verified evidence model; progress-report workflow; transparent ETA/readiness; compatibility registry; rescue acquisition wedge; studio/customer segment; and conservative OAuth/read-only security model.

## Scope resolution
The first sellable wedge may be Blueprint + GitHub/Vercel observation + progress verification. The broader connected MVP is not considered complete until Supabase/code/database intelligence lands. This avoids scope explosion without discarding the stronger long-term differentiation.
